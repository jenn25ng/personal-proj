# 테스트셋

이 폴더의 자료는 **샘플**이다. 여기에 맞춰 프롬프트·분류·필터를 조정하지 않는다.

- `real-child-messages.jsonl`: 실제 초등 6학년 아이의 메시지 107개(챗지피티 대화 두 건과 스크린샷). 아이 한 명, 주제 하나의 기록이므로 "아이들은 이런 성향으로 쓴다"는 경향을 읽는 데 쓴다. `expect.mode`는 어떤 종류의 메시지가 오는지 보여 주는 예시이고 맞혀야 할 정답표가 아니다. 유일하게 꼭 지켜야 하는 기대값은 `expect.filter=pass`, 즉 정상적인 아이 메시지가 안전 필터에 걸리면 안 된다는 것이다. 분석은 `docs/실사용-대화-분석.md`.
- `guardrail-cases.json`: 안전 필터 기대값. 규칙은 이 목록이 아니라 종류 단위로 고친다. `known_gap`은 아직 못 잡는 것으로 알고 있는 사례.
- 실행: `pnpm test:rules` (키 없이 돈다).
