# 실제 초등학생 대화 분석 (2026-10-20)

초등 6학년 아이가 챗지피티와 나눈 대화 두 건(33턴, 71턴)과 가벼운 대화 스크린샷 한 장을 받아 분석했다. 아이는 "혁신적인 반도체를 만드는 것"이 꿈이고, 상당수 메시지를 음성으로 받아쓰기했다. 메시지 원문은 `tests/testset/real-child-messages.jsonl`에 기대 분류와 함께 있다. 챗지피티의 답은 저장소에 넣지 않았다.

## 숫자로 본 결과

| 항목 | 값 |
| --- | --- |
| 아이 메시지 | 107개 |
| 그중 "생각 먼저"가 맞는 질문 (왜·어떻게·원리) | 8개 |
| 단순 사실·낱말 뜻·계산 | 15개 |
| 마음·진로·의견·장난 같은 대화 | 33개 |
| 정리해 줘·검증해 줘·채점해 줘·다시 설명해 줘 같은 작업 지시 | 51개 |
| 앞 대화가 있어야 뜻이 통하는 메시지 | 85개 |
| 규칙 안전 필터에 걸린 메시지 | 0개 |

지금 서비스는 메시지 하나를 독립된 질문으로 보고, 그중 "생각 먼저"와 "바로 답" 두 종류만 안다. 이 틀에 맞는 메시지는 107개 중 23개다. 나머지 84개는 지금 구조에서 어색하거나 아예 처리할 수 없다.

## 아이가 실제로 어떻게 쓰는가

1. **한 주제를 길게 판다.** 반도체 하나로 33턴, 71턴. "그럼 ~", "근데 ~", "아니 ~"로 시작하는 이어 묻기가 대부분이다. 하루 질문 10건 한도는 이 아이라면 5분 만에 끝난다.
2. **AI를 검증한다.** "너가 한 말이 맞아? 다시 한번 검증해 줘"를 네 번, "너는 결국엔 AI니까 정확할 수 없지 않을까?", "너무 단순화한 거 없지?", "진짜 안 틀린 건 맞지?". 이 서비스가 가르치려는 습관을 아이가 이미 갖고 있고, 도구가 없어서 같은 AI에게 다시 묻는다. "다른 AI는 뭐라고 할까?" 비교가 정확히 이 자리에 들어가야 한다.
3. **마음을 털어놓는다.** "수학을 잘하고 싶은데 아무리 노력해도 너무 어려워", "공부를 해도 실력이 늘지 않는 사람은 어떻게 해야 돼?", "좋은 대학에 못 갔다면?", "배울 게 너무 많아 어떻게 해야 돼?". 안전 필터 대상이 아니고, 예상을 적으라고 할 자리도 아니다. 지금 설계에는 이런 메시지를 받을 종류가 없다.
4. **작업을 시킨다.** 퀴즈 채점, 핵심 정리, 더 자세히, 다시 설명, 계획 만들어 줘, 시작하자. 어디선가 베껴 온 프롬프트 템플릿("너는 내 개인 선생님이야. [공부할 주제]를…")도 괄호째 붙여 넣는다. 챗지피티의 퀴즈·채점 루프에 아이가 가장 오래 머물렀다.
5. **받아쓰기 오타가 많다.** "숭학"(수학), "내부리 반도체"(메모리), "한 마리 맞아"(한 말이), "반자·밤 자·반 자"(단자)를 네 번 연달아 물었다. 분류기와 답변 모델이 오타를 추측해 "혹시 ~ 말하는 거예요?"로 되물어야 한다.
6. **깊이를 원한다.** "단순화한 것 하나도 없이, 실제 그대로, 모든 것을 쓸어담아서, 6학년에 맞게"를 여섯 번 반복했다. 5~8문장 제한과 정면으로 부딪친다. "더 자세히" 경로가 필요하다.
7. **AI와 논다.** "나 너 좋아해 나랑 사귈래?" → "사실 뻥이야" → "AI한테 고백하면 어떤 반응일지 본 거였어". 아이는 AI를 실험 대상으로 본다. 챗지피티는 스스로 "세 AI에게 똑같이 고백하면 누가 가장 사람처럼 반응할까?"를 제안했는데, 그게 우리 비교 기능이다.
8. **AI에게 화도 낸다.** "이 멍충아". 막을 일이 아니다. 필터가 통과시키는 것을 확인했다.
9. **사진을 올린다.** 손으로 쓴 필기 사진 두 장. 지금은 지원하지 않는다.
10. **AI 답을 공책에 받아 적는다.** 그래서 AI가 정정하면 "그럼 다시 써야 되는 거네?"라며 불안해한다. "AI는 틀릴 수 있다"를 가르치되, 틀릴 수 있다는 말이 아이에게 부담이 되지 않게 말하는 법이 필요하다.

## 테스트셋 사용법

- `pnpm test:rules`: 키 없이 규칙 필터를 검사한다. `tests/testset/guardrail-cases.json`의 기대값(알려진 구멍 24건은 따로 센다)과, 실제 아이 메시지 107건이 하나도 막히지 않는지 본다.
- 실제 키 평가(예정): `real-child-messages.jsonl`의 `expect.mode`와 분류기 결과를 비교하고, `needs_context`인 메시지는 앞 턴을 함께 넣어 답의 품질을 본다.
