# 하루 — 할 일과 일기

매일 반복하는 일을 체크하고, 그날의 일기를 쓰고, 그 일기를 블로그용 마크다운으로 뽑아내는
단일 파일 웹앱입니다. 서버도 설치도 필요 없습니다.

## 쓰는 법

`index.html` 파일을 브라우저로 열면 끝입니다.

- 데스크톱: 파일을 더블클릭하거나 브라우저 창에 끌어다 놓기
- 자주 쓴다면 북마크에 등록해 두기
- 어디서나 쓰고 싶다면 GitHub Pages로 올리기
  (저장소 Settings → Pages → Branch를 `claude/daily-todo-diary-app-8lxcsb`(또는 병합 후 기본 브랜치)로 지정)
- 폰: 페이지를 열고 "홈 화면에 추가"하면 앱처럼 실행됩니다

## 기능

**오늘 탭**
- *매일 하는 것*: 한 번 등록해 두면 매일 체크박스로 나오는 루틴. 진행률 막대와 "N일 연속" 표시
- *오늘 할 일*: 그날만의 할 일. 어제 못 끝낸 일은 "어제 남은 일 N개 가져오기" 한 번으로 이월
- 헤더의 화살표(또는 ← → 키)로 지난 날짜/다음 날짜 이동

**일기 탭**
- 기분 이모지, 제목, 본문, 태그. 입력하는 즉시 자동 저장됩니다
- **말하기** 버튼: 마이크로 말하면 그대로 받아 적습니다
  (Web Speech API, 한국어. Chrome·Edge에서 동작하며 Safari·Firefox에서는 버튼이 숨겨집니다)

**기록 탭**
- 달력에 일기 쓴 날(초록 점)과 할 일을 끝낸 날(회색 점)이 표시됩니다. 날짜를 누르면 그날로 이동
- 지난 일기 목록과 검색(제목·본문·태그)
- 백업 내려받기 / 불러오기 / 전체 삭제

**발행 탭**
- 기간 선택: 이 날짜 / 최근 7일 / 이번 달 / 전체
- 옵션
  - `front matter`: 정적 블로그(Jekyll·Hugo·Astro 등)용 `title`/`date`/`tags` 머리말 추가
  - `문단 자동 정리`: 말하듯 주르륵 쓴 글을 세 문장씩 문단으로 나눠 줍니다.
    빈 줄로 직접 문단을 나눈 글은 그 구분을 그대로 존중합니다
  - `할 일 요약 포함`: 그날 체크한 루틴·할 일을 체크리스트로 덧붙임
  - `기분 표시`: 제목 옆 이모지와 front matter의 `mood`
- **마크다운 복사** 또는 **.md 내려받기** → 티스토리·벨로그·Notion·GitHub Pages 등에 그대로 붙여넣기

출력 예시:

```markdown
---
title: "오랜만에 정리한 하루"
date: 2026-08-20
tags: [일상, 회고]
mood: 뿌듯
---

오늘은 아침부터 밀린 일을 정리했다. 생각보다 금방 끝나서 기분이 좋았다. 점심엔 오랜만에 국수를 먹었다.

오후엔 산책을 30분 정도 했다. 날씨가 선선해서 걷기 좋았다. 저녁엔 책을 조금 읽다가 잠들었다.

### 그날 한 일
- [x] 물 2L 마시기
- [x] 30분 산책
- [ ] 민수한테 전화
```

## 데이터가 저장되는 곳

모든 기록은 **그 브라우저의 localStorage**에만 저장됩니다. 서버로 아무것도 전송되지 않고,
계정도 필요 없습니다. 대신 이런 점을 주의하세요.

- 브라우저 방문 기록/사이트 데이터를 지우면 함께 지워집니다
- 기기나 브라우저가 다르면 기록이 공유되지 않습니다
- 시크릿 창에서 쓰면 창을 닫을 때 사라집니다

그래서 **기록 탭의 "백업 내려받기"** 로 가끔 JSON 파일을 받아 두는 걸 권합니다.
다른 기기에서는 "백업 불러오기"로 그 파일을 넣으면 그대로 복원됩니다.
